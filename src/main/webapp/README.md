# 猜单词游戏

一个基于Vue.js的猜单词游戏，无需后端支持，纯前端实现。

## 功能特点

1. **单词猜测**：随机从100+个日常生活常见单词中选择一个单词
2. **字母显示**：每个字母用下划线表示，猜对的字母会显示在对应位置
3. **次数限制**：玩家可以自定义最大猜测次数（5-20次）
4. **提示系统**：每猜错三次可以获得一次提示，最多3次提示
5. **游戏状态**：清晰的游戏开始、进行中和结束界面
6. **响应式设计**：适配不同屏幕尺寸

## 游戏规则

1. 打开index.html文件开始游戏
2. 输入最大猜测次数（5-20次），点击"开始游戏"
3. 看到下划线表示的单词长度，输入字母进行猜测
4. 猜对的字母会显示在对应位置，猜错会消耗一次机会
5. 每猜错三次可以点击"获取提示"获得相关提示信息
6. 在次数用完前猜完所有字母则胜利，否则失败
7. 游戏结束后可以点击"再玩一次"重新开始

## 使用方法

直接在浏览器中打开index.html文件即可开始游戏，无需任何服务器或后端支持。

## 单词库

游戏包含100+个日常生活常见单词，涵盖以下类别：
- 水果类（apple, banana, orange等）
- 动物类（cat, dog, bird等）
- 交通工具类（car, bus, train等）
- 学习用品类（book, pen, pencil等）
- 家居类（house, room, kitchen等）
- 电子设备类（computer, phone, tablet等）
- 自然类（sun, moon, tree等）
- 食物类（food, bread, rice等）
- 艺术类（music, song, piano等）
- 情绪类（happy, sad, angry等）
- 颜色类（red, blue, green等）

## 提示系统

部分单词配有相关提示信息，帮助玩家更好地猜测单词。

## 开发说明

本项目为纯前端项目，无需安装任何依赖。如需修改或扩展：

1. 修改game.js中的wordLibrary数组可以添加或修改单词
2. 修改hintLibrary对象可以添加或修改提示信息
3. 修改styles.css可以调整游戏样式
4. 修改index.html可以调整页面结构

## 浏览器兼容性

支持所有现代浏览器（Chrome, Firefox, Safari, Edge等）。
