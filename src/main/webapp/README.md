# 猜单词游戏 (Word Guess Game)

一个基于 Vue.js 的猜单词游戏，包含完整的游戏逻辑和美观的界面。

## 功能特点

- 🎮 **简单易用**：直观的游戏界面，易于上手
- 📚 **丰富词库**：包含超过 150 个日常生活常用单词
- 🎯 **自定义难度**：可设置 5-20 次的最大猜测次数
- 💡 **智能提示**：每猜错 3 次获得一次相关提示
- ⌨️ **虚拟键盘**：支持鼠标点击和键盘输入两种方式
- 📊 **实时统计**：显示剩余次数、已猜字母、正确率等信息
- 📱 **响应式设计**：适配各种屏幕尺寸

## 游戏规则

1. **开始游戏**：在游戏设置界面输入最大猜测次数（5-20次），点击"开始游戏"
2. **猜测字母**：使用虚拟键盘或输入框输入字母进行猜测
3. **查看结果**：正确猜测的字母会显示在对应位置，错误猜测的字母会标记为红色
4. **获得提示**：每猜错 3 次，系统会提供一条相关提示
5. **游戏结束**：
   - 在猜测次数内猜出所有字母，游戏胜利
   - 用完所有猜测次数仍未猜出，游戏失败

## 技术实现

- **前端框架**：Vue.js 2.6.14
- **样式设计**：CSS3（渐变、动画、响应式布局）
- **数据结构**：包含单词库、分类库和提示库
- **游戏逻辑**：完整的状态管理和游戏流程控制

## 使用方法

1. **直接打开**：用浏览器直接打开 `word-guess-game.html` 文件即可开始游戏
2. **本地服务器**：
   ```bash
   # 使用 Python 启动简单服务器
   python -m http.server 8000
   
   # 使用 Node.js 启动服务器
   npx serve .
   ```
   然后在浏览器中访问 `http://localhost:8000`

## 开发说明

如果需要修改或扩展游戏：

1. **添加单词**：在 `game-logic.js` 的 `wordDatabase` 数组中添加新单词
2. **添加分类**：在 `wordCategories` 对象中为新单词指定分类
3. **添加提示**：在 `hintDatabase` 对象中为分类添加提示信息
4. **修改样式**：编辑 `game-styles.css` 文件自定义界面
